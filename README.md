# LifeChange — Privacy Policy

This application is a personal tool used by the owner of the Etsy shop
"LifechangeDaJnoc" to publish the shop's own products as Pins on the owner's
own Pinterest account.

Data use: the app accesses only the owner's own Pinterest boards and pins,
to create pins linking to the owner's Etsy listings. It does not collect,
store, or share personal data of other Pinterest users. The authentication
token is stored only locally on the owner's computer.

No data is sold or shared with third parties.
